# coi-pages

The pages behind infusion.themomentumcompany.com for Cup of Infusion (Jon Anderson, The Momentum Company).

- `.github/workflows/publish.yml` copies the audio player from marvinforever/cj-pages every 15 minutes, swaps in Jon's name, and publishes with GitHub Pages.
- `index.html` is the home page. It has no sign-up form on purpose: people join through the program invite and reply YES.
- Brand colours and names on the player come from the `coi` row in `cj_brands` (style), not from this repo.
- No keys ever go in this repo. It is public.
